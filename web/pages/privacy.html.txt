<h1>隱私權政策</h1>
<p class="meta">最後更新：2026 年 11 月 24 日</p>
<p>「片刻」用來查詢台灣電影場次，並把場次加入行事曆。它有網頁版、iPhone App，以及在 Scriptable、Scripting 裡執行的腳本版，本政策適用於全部版本。</p>
<p>簡單說：不用註冊、沒有廣告、不追蹤個人。網頁版只有不辨認個人的造訪統計。</p>

<h2>不要求你提供個人資料</h2>
<p>沒有會員註冊、留言或訂票功能。使用任何功能都不需要提供姓名、電子郵件或電話。</p>

<h2>會傳到我們伺服器的資料</h2>
<p><strong>片刻評分</strong>：你替電影評分（1～10 分）時，會把「片名、分數、一組匿名代號」送到評分伺服器（Cloudflare Workers），用來計算平均分數，並確保一台裝置只算一票。</p>
<p><strong>心得標籤</strong>：評分後可以點選幾個固定的選項（例如「催淚」「有片尾彩蛋」），送出的是「片名、你選的選項、同一組匿名代號」，用來統計各選項有多少人選。這裡不能輸入文字，所以不會收到任何你寫的內容；取消評分時，選過的標籤會一起刪除。</p>
<ul>
<li>匿名代號是第一次使用時隨機產生的一串英數字，存在你的裝置上。它不是裝置序號或廣告識別碼，也對應不到你的姓名、帳號或聯絡方式。</li>
<li>為了防止灌票，伺服器會在短時間內（約 10 分鐘）依來源 IP 位址計算投票次數，之後自動清除，不長期保存。</li>
<li>再點一次已選的分數就能取消評分。</li>
</ul>
<p><strong>用 Google 登入同步設定</strong>（只有網頁版，而且要你自己在設定裡登入）：登入後，我們把以下資料存在伺服器（Cloudflare）上，讓你在別的裝置或瀏覽器登入同一個帳號時可以帶過來：</p>
<ul>
<li>你的 Google 帳號識別碼經過雜湊後的結果（看不出是哪個帳號；我們不存 email、姓名、大頭貼）</li>
<li>會同步的設定：收藏影城、收藏電影、收藏發行商、廣告時間、地圖偏好、通知的選項</li>
</ul>
<p>登入時你會被帶到 Google 的登入頁，Google 會知道你登入了這個網站。你可以隨時在設定裡登出，或選「刪除帳號裡的資料並登出」，伺服器上的這些資料會立刻刪除。不登入的話，以上資料只存在你的裝置上。</p>
<p><strong>收藏電影通知</strong>（只有網頁版，而且要你自己在設定裡開啟）：開啟後，你的瀏覽器會產生一組「推送位址」，我們把它連同以下資料存在伺服器（Cloudflare）上，用來在對的時間通知你：</p>
<ul>
<li>你收藏的電影片名（影展片另外記是哪個影展）</li>
<li>你要哪幾種通知（開放場次、上映前提醒、上映、收藏影城開始放映、特殊廳、評分出爐、快下檔、影展開始、每週新片、收藏影城每週新片、影展片單公布）</li>
<li>通知的細項設定：特殊廳要哪幾種、上映前幾天提醒、勿擾時段；開了「收藏影城開始放映時」或「收藏影城每週新片」的話，還有你收藏的影城代碼</li>
<li>「快下檔」的設定：剩下幾間以下才通知，以及算哪些影城（全台、你選的縣市、你收藏的影城，後兩者可以一起選。只有選了「收藏影城」時，才會把收藏影城代碼傳上來）</li>
<li>哪些通知已經發過（避免重複）</li>
</ul>
<p>推送位址是瀏覽器隨機產生的，對應不到你的姓名、帳號或聯絡方式；我們也不記錄 IP 位址。沒有開啟通知的話，收藏電影只存在你的裝置上，不會傳給我們。</p>
<p>收到的通知會在你的裝置上留一份紀錄（「最近的通知」，最多 50 則、30 天），只存在裝置上，不會傳到伺服器。</p>
<p>你可以隨時在設定裡關閉通知，關閉時伺服器上的這些資料會立刻刪除。如果你直接在系統設定關掉通知、或移除主畫面上的「片刻」，推送位址會失效，我們下次要發通知時發現失效就會刪除。通知是透過你所用瀏覽器的推送服務（Apple、Google、Mozilla 或 Microsoft）送達，內容在送出前已經加密，推送服務看不到內容。</p>
<p>除此之外，我們沒有收集任何個人資料。</p>

<h2>伺服器紀錄</h2>
<p>網頁版與評分伺服器托管於 Cloudflare，整理好的電影資料放在 GitHub。和大多數網站一樣，這些服務可能自動記錄 IP 位址、瀏覽器類型、造訪時間與請求的網址，用於維持服務安全、防止濫用。我們不會用這些紀錄辨識個人身分，也沒有另外保存。</p>
<p><strong>網頁版的代為讀取</strong>：瀏覽器不能直接讀取其他網站的場次，所以網頁版會請我們的伺服器代為讀取影城與電影資料網站的公開頁面，再把結果傳回給你。伺服器只轉送，不保存你查了什麼。</p>

<h2>只留在你裝置上的資料</h2>
<ul>
<li><strong>位置</strong>：只有在你使用「附近的影城」或選「附近 10 間」時才會取得，用來在裝置上計算與各影城的距離，不會傳到我們的伺服器。</li>
<li><strong>行事曆</strong>：App 只要求「新增行程」的權限，讀不到你行事曆裡原有的內容。網頁版是下載一個行事曆檔，由你自己打開加入。</li>
<li><strong>設定</strong>：收藏影城、收藏電影、廣告時間、提醒、地圖偏好，都只存在裝置上（收藏電影在你開啟通知時會另外傳到伺服器，見上面「收藏電影通知」）（網頁版存在瀏覽器的本機儲存空間）。</li>
<li><strong>快取</strong>：場次、海報等資料會暫存在裝置上以加快顯示。刪除 App，或清除瀏覽器的網站資料，就會一併清除。</li>
</ul>

<h2>Cookie、使用統計、瀏覽器儲存空間與廣告</h2>
<p>我們不使用 Cookie，沒有放任何廣告，也不會追蹤個別的使用者。</p>
<p><strong>網頁版的使用統計</strong>：為了知道大概有多少人在用、用什麼裝置，好安排開發的優先順序，網頁版使用 Cloudflare Web Analytics（Cloudflare 提供的網站分析）。它不使用 Cookie、不在你的瀏覽器存任何東西，也不會建立可以辨認個人的紀錄。統計的內容是彙總的數字：造訪次數、瀏覽的頁面、從哪個網站連過來、國家、瀏覽器與作業系統的種類、裝置類型（手機或電腦），以及頁面載入的速度。這些資料由 Cloudflare 依其隱私權政策處理，我們只看得到彙總後的統計。iPhone App 與腳本版沒有這項統計。</p>
<p>網頁版會用到瀏覽器的「本機儲存空間」（localStorage、sessionStorage）。它和 Cookie 一樣是存在你瀏覽器裡的資料，但只有這個網站自己讀得到，不會隨著連線自動送出，也不會用來追蹤你。存的東西只有讓功能運作所需要的：</p>
<ul>
<li><strong>設定</strong>：收藏影城、收藏電影、廣告時間、提醒、地圖偏好。</li>
<li><strong>快取</strong>：查過的場次、電影資料與海報網址，用來加快顯示；會自動過期、空間不夠時自動清掉。</li>
<li><strong>評分用的匿名代號、你評過的分數與選過的心得標籤</strong>：讓評分一台裝置只算一票，並在畫面上顯示你給過的分數和標籤。</li>
<li><strong>版本記號</strong>：網站更新後自動重新載入一次用的，關掉分頁就消失。</li>
</ul>
<p>這些都只存在你的瀏覽器裡。要清除的話，到瀏覽器的設定清除這個網站的資料即可；清除後收藏影城等設定會回到預設值。因為只存功能必要的資料、使用統計也不用 Cookie、不辨認個人，所以進站時不會跳出 Cookie 同意視窗。</p>

<h2>第三方網站</h2>
<p>App 與腳本版會直接向下列網站讀取公開資料；網頁版則由我們的伺服器代為讀取。和你用瀏覽器造訪這些網站一樣，對方會看到連線的 IP 位址與一般連線資訊，並依各自的隱私權政策處理：</p>
<ul>
<li>場次通（twshowtimes.com）、開眼電影網（atmovies.com.tw）與各影城官網：場次、片長、海報</li>
<li>GitHub（raw.githubusercontent.com）：我們整理好的電影資料、場次、票房排行、即將上映片單、影展場次、片刻評分統計</li>
<li>IMDb、爛番茄：電影評分</li>
<li>The Movie Database（TMDB）：部分海報圖片放在 TMDB 的圖片伺服器</li>
<li>海報與劇照圖片：畫面上的圖片由你的裝置直接向圖片所在的網站下載（TMDB、IMDb、開眼電影網、YouTube，以及各影展官網）</li>
<li>YouTube：尋找與開啟預告片</li>
<li>Cloudflare Web Analytics（static.cloudflareinsights.com）：只有網頁版，送出不辨認個人的造訪統計</li>
</ul>
<p>你點「訂票」「導航」「觀看預告」或評分連結時，會開啟影城官網、地圖、YouTube 等外部網站或 App。它們有各自的隱私權政策，不在本政策範圍內。</p>
<p>我們不會把你的資料賣給或分享給任何第三方。</p>
