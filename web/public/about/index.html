關於電影行程

「電影行程」是一個免費的台灣電影場次查詢工具。選一間影城或一部電影，挑好場次後，一鍵把它加入行事曆：會依片長與廣告時間算出散場時間，並附上影城地址與訂票連結。

它有網頁版、iPhone App，以及在 Scriptable、Scripting 裡執行的腳本版，四個版本用的是同一套資料。

為什麼做這個

訂好電影之後，常常還要自己開行事曆、查片長、算幾點散場、找影城地址。這個工具想把這幾步合成一步，順便回答幾個常見的問題：現在出門還趕得上哪幾場？這部片哪裡有 IMAX？常去的那幾間今晚在演什麼？

感謝場次通

全台 66 間連鎖影城的場次，來自 場次通（twshowtimes.com）。場次通由橫隔膜 Halami 獨立製作與維護，把威秀、國賓、美麗華、秀泰、喜樂時代、中影、新光、in89、百老匯等九大連鎖的場次整理在同一個地方，並把各家不同寫法的片名對齊成同一部片。

沒有場次通的整理，這個工具做不出來。想比較各影城的場次、看上映場數排行與特殊廳統計，請直接造訪場次通。

電影行程讀取的是場次通公開的網頁，與場次通沒有合作或隸屬關係，也不代表場次通的立場。

資料怎麼來

  • 連鎖影城的場次、片長、分級：場次通，共 66 間。
  • 其他戲院的場次，以及海報、預告、片長：開眼電影網，共 37 間；另外補上五間威秀的 Gold Class、MUCROWN、TITAN 等頂級影廳場次。
  • 誠品電影院、光點華山、光點台北、樂聲影城：各自的官網時刻表。
  • 票房排行：國家電影及視聽文化中心「全國電影票房統計」開放資料，依政府資料開放授權條款第 1 版使用。
  • 評分：IMDb、爛番茄的公開頁面；「觀眾評分」是使用者在這裡自己點的星星。
  • 預告：開眼電影網頁面上的預告，或 YouTube 上標題對得上台灣片名的影片；沒有把握時只提供搜尋連結。
  • 海報與上映日期：依序取自場次通、開眼電影網、IMDb；填了自己的 TMDB 金鑰時也會用 TMDB。

資料多久更新

  • 場次、海報、預告、評分由排程定期整理成檔案，實際上大約每幾個小時更新一次；太久沒更新時，App 會改成直接讀取來源網站。
  • 票房排行每天檢查一次，官方資料大約每週更新。
  • 觀眾評分的統計大約每幾個小時彙整一次。

使用前請知道

  • 場次以各影城官網公告為準，可能因臨時加場、取消而變動。訂票前請點「訂票／官方」到影城官網再確認一次。
  • 片長有時來自原版或其他來源，散場時間是估算值。
  • 票房排行裡標「上映至今」的新片，是官方第一次列入的資料，數字是上映以來的累計，不是單週票房。
  • 電影行程不販售電影票，與各影城、上述網站都沒有合作或隸屬關係。各網站的名稱與標誌屬於其所有人。
  • This product uses the TMDB API but is not endorsed or certified by TMDB.

製作與原始碼

電影行程是個人製作的開放原始碼專案，程式碼與安裝方式在 GitHub。發現場次有誤或有建議，歡迎到 GitHub 提出。
