# 金馬影展場次：可行性評估與待辦

評估日期：2026-11-22（當年影展 11/6–11/22 的最後一天）。結論：**做得起來，等下一屆場次表公布後再實作**，實作前要先跟使用者確認修改內容。

## 目前狀況

- App 的四個版本都沒有影展場次。場次通、開眼電影網、官網來源的現有資料裡，搜「金馬」「影展」都是 0 筆——影展場次由另外的售票系統販售，影城的一般時刻表不會列。
- 唯一相關的處理：光點華山時刻表出現「影展／包場」字樣時，會提示官網沒列出的個別場次不會出現。

## 來源測試結果

從 GitHub Actions 的機器讀取（用 `.github/workflows/probe.yml`，手動執行、只讀不寫）：

| 網址 | 結果 |
|---|---|
| `https://www.goldenhorse.org.tw/` | 200，一般 PHP 網頁（Apache），沒有 Cloudflare／Akamai 防護 |
| `/film/programme/films/` | 200，片單，有各片詳細頁連結 `/film/programme/films/detail/<編號>?search_year=<年>&search_category=FF` |
| `/film/programme/schedule/` | 200，場次直接寫在網頁裡 |
| `/film/programme/films/detail/<編號>` | 200，有年份、片長、分級、簡介（`og:description`） |
| `/robots.txt` | 200，內容空白 |
| `https://tixcraft.com/`（拓元） | 403，`{"response":"block"}`，明確擋掉自動讀取 |

場次頁每一筆有：影廳（例：`TITAN`、`台北信義威秀 10廳`）、時間、片名、片長、分級，以及「前往購票」連結 `https://tghff.tixcraft.com/ticket/area/<活動代碼>/<場次編號>`。

**拓元不用讀**：只要把官網給的購票連結原樣帶出來，讓使用者自己開瀏覽器購票。代價是看不到剩餘票數、是否售完。

注意：這個開發環境（Claude Code 雲端容器）連不到 goldenhorse.org.tw 和 tixcraft.com，要看網頁內容只能透過上面的 probe 排程，或請使用者提供。

## 還沒確認的

1. 場次頁怎麼切換日期（網址參數或頁面內切換）——決定要讀幾頁才能拿到整個影展的場次。評估時只看到當天。
2. 下一屆官網會不會改版。樣式檔名帶 2023–2025 的日期，看起來每年沿用同一套系統小改，但沒有保證。
3. 影展片名是影展譯名，之後院線上映可能改名：海報、評分的比對要另外處理。

## 建議的做法（實作前要先跟使用者確認）

- 比照場次通：伺服器預抓成一個檔（data 分支），四個版本共用。
- 影展期間，在「電影」分頁多一個「影展」分類，列片單與場次。
- 點場次可以加進行事曆，附官網的購票連結。
- 不做搶票、選位、剩餘票數。
- 可以考慮做成通用的「影展」功能，之後台北電影節（6–7 月）、高雄電影節（10 月）沿用。

## 時程參考（2026 年）

- 9 月中、下旬：公布片單與開閉幕片
- 10/25：單場預售開賣（場次表在這之前公布）
- 11/6–11/22：影展
